# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/101KzKialuVyEPma6eSUZg8oYm5pweIre

## Run Locally


1. Clone this repository:
   `git clone https://github.com/jennazch/jenna.git`
2. Go into the cloned repository:
   `cd path/to/repo`
3. Serve on port 8000:
   `python3 -m http.server 8000`
4. Access port 8000 in browser by navigating to http://localhost:8000/
